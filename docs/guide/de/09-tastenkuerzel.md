# Tastenkürzel

*Ansicht → Tastenkürzel* zeigt dieselbe Liste in ScoreArt.

| Taste | Aktion | Taste | Aktion |
|---|---|---|---|
| `N` | Noteneingabe an/aus | `Esc` | Noteneingabe verlassen / Auswahl aufheben |
| `A`–`G` | Note eingeben | `Umschalt+A`–`G` | Note zum Akkord hinzufügen |
| `1`…`8` | 64tel … Brevis (5 = Viertel) | `.` | Punkt |
| `0` | Pause | `T` | Haltebogen |
| `↑` `↓` | Halbton hoch/runter | `Strg+↑` `Strg+↓` | Oktave |
| `Alt+Umschalt+↑/↓` | Tonleiterschritt | `←` `→` | vorige/nächste Note |
| `Strg+←/→` | voriger/nächster Takt | `Strg+Alt+↑/↓` | System darüber/darunter |
| `Strg+Alt+1…4` | Stimme | `Entf` | Löschen |
| `Strg+B` | Takt anhängen | `Einfg` | Takt einfügen |
| `Strg+Z` / `Strg+Y` | Rückgängig / Wiederherstellen | `Strg+L` | Liedtext |
| `Strg+S` / `Strg+Umschalt+S` | Speichern / Speichern unter | `Strg+O` / `Strg+N` | Öffnen / Neu |
| `Leertaste` | Abspielen / Stopp | `Esc` | Wiedergabe anhalten |
| `S` | Bindebogen über die Auswahl | `<` / `>` | Crescendo- / Decrescendo-Gabel |
| `/` | Vorschlagsnote | `Umschalt+→` | Auswahl erweitern |
| `Strg+K` | Akkordsymbol | `Strg+T` / `Strg+M` | Systemtext / Studierzeichen |
| `F10` | Mixer | `I` | Instrumente und Klänge |
| `Strg+F1` | Ribbon ein-/ausklappen | | |

Auf dem Mac ist `Strg` die Taste `⌘`.
